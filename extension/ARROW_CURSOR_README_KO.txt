Annotate Web Chrome - 일반 화살표 커서 + 선 보정

변경점
- 웹페이지 주석 모드가 켜져 있는 동안 텍스트, 링크, 입력칸 위에서도 일반 화살표 커서가 유지됩니다.
- 주석 도구 모음의 버튼과 슬라이더는 기존의 클릭 가능한 커서가 유지됩니다.
- Annotate Web 텍스트 삽입 도구의 입력칸(#textInput)에서는 글자 입력용 커서가 유지됩니다.
- 주석 모드를 끄면 삽입된 커서 스타일을 제거하여 웹페이지의 원래 커서로 돌아갑니다.
- 기존 선 보정 및 그리기 기능은 그대로 유지됩니다.

설치/업데이트
1. ZIP 압축 해제
2. Chrome 주소창 chrome://extensions
3. 개발자 모드 활성화 → 압축해제된 확장 프로그램을 로드합니다.
4. AnnotateWeb_Chrome_Smooth 폴더(안에 manifest.json 있음) 선택
5. 기존 Annotate Web 확장은 충돌하지 않도록 비활성화합니다.
6. 웹페이지 새로고침 후 확장 프로그램을 켜고 텍스트 위에서 마우스 모양을 확인합니다.

참고: Chrome의 확장 프로그램 삽입이 허용되지 않는 페이지에서는 동작하지 않습니다.
