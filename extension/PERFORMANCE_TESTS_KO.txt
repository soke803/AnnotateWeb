v1.2.3 검증 메모 (2026-11-10)

검증 환경
- Linux Chromium, Playwright 실제 마우스/키보드 입력.
- 1200 × 800 화면, DPR 1 및 DPR 2.
- 일반 긴 문서(root), 내부 스크롤 대화 화면(nested),
  큰 sticky 콘텐츠(tall)를 로컬 페이지로 재현.
- 서비스/저장소의 Chrome API만 대체하고 draw.js와 shortcut.js를 브라우저에서 실행.
- 실제 ChatGPT 로그인 대화에서 직접 측정한 결과는 아님.
- 환경의 ExtensionInstallBlocklist 관리 정책으로 임의의 로컬 확장 설치가
  금지되어 실제 MV3 확장 로더 통합 검증은 수행하지 못함.

토글 측정 방식
화면 반영을 기다리는 requestAnimationFrame 2회가 포함된 토글 시간이며,
자바스크립트 함수 실행 시간만 측정한 값이 아님.
스타일 재계산은 Chrome DevTools Protocol의 RecalcStyleDuration으로 측정.
동일 페이지에서 OFF/ON 각 8회, 총 16회 토글함.

- nested: 토글 212.8~235.2ms, 16회 합계 스타일 재계산 3051.5ms.

기능 검증
- 그리는 중 미리보기 및 펜을 놓은 후 완성된 선 표시.
- 실행 취소/다시 실행과 새로고침 후 저장된 그림 복원.
- 내부 대화 창 스크롤 후 그림 위치 유지.
- 큰 sticky 요소의 캔버스: 원본 860 × 26,000 → 수정본 860 × 600 (DPR 1).
- 휠/트랙패드 전달, smooth scroll 속성의 내부 창으로만 스크롤 전달.
- ON 상태 페이지 링크 클릭 차단, OFF 상태 일반 클릭 복구.
- 도구 모음 선택 및 한글 텍스트 입력·저장.
- DPR 2에서 캔버스 해상도 및 위 기능 재검증.
- OFF 상태에서 스크롤·크기 변경 후 ON 시 위치·해상도 갱신.
- 펜을 놓자마자 pagehide 발생 시 지연 저장 즉시 처리.
- 720ms 동안 펜을 누른 상태에서 기록 저장이 실행되지 않음을 확인.
- 한 번 클릭한 점의 새로고침 후 복원.
- 부모 스크롤로 캔버스 크기가 바뀔 때 빈 프레임 없이 표시 유지.
- DOCTYPE 없는 quirks 문서에서도 루트 캔버스가 화면 크기를 넘지 않음.
- 추가 경계 조건 8개 모두 통과.
- draw.js / background.js / shortcut.js 문법 검사.

수치는 이 재현 환경의 측정값이며 컴퓨터, 페이지 내용, 브라우저 상태에 따라 달라짐.
