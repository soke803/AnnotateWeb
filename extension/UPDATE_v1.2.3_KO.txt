Annotate Web v1.2.3 — 긴 대화 토글 / 펜 입력 지연 개선

설치·업데이트
1. 이 ZIP을 압축 해제합니다.
2. 기존 확장 프로그램을 업데이트하려면, 기존에 로드한 확장 폴더를 백업한 뒤
   새 폴더 안의 파일들을 기존 폴더에 덮어씁니다. manifest.json이 바로 보이는
   폴더가 확장 프로그램 폴더입니다.
3. chrome://extensions에서 해당 확장 프로그램의 새로고침 버튼을 누릅니다.
   새로 설치하는 경우 개발자 모드 → '압축해제된 확장 프로그램을 로드합니다'로
   manifest.json이 있는 폴더를 선택합니다.
4. 열려 있던 ChatGPT 및 사용 중인 웹페이지도 새로고침합니다.
   이전 탭에 남아 있는 v1.2.2 실행 코드가 교체되어야 수정 사항이 적용됩니다.
5. 기존 단축키 Alt/Option + ` 및 확장 아이콘으로 켜고 끕니다.

수정 내용
- 토글 때 html/body/body * 전체에 적용·해제하던 커서/선택 방지 규칙을 제거했습니다.
  화면 크기의 독립된 입력 레이어에서 커서와 페이지 입력 차단을 처리합니다.
  긴 대화의 모든 요소를 다시 스타일 계산하는 부담을 줄입니다.
- 그리기 캔버스는 현재 화면 및 각 방향 최대 128px 주변으로 제한합니다.
  내부 스크롤 창의 경계도 반영하며, 화면 밖의 큰 sticky/overflow 요소 때문에
  대화 전체 높이만큼 캔버스가 커지지 않게 했습니다.
  기존 그림 데이터는 유지하고, 이동한 화면에 해당하는 부분을 다시 표시합니다.
- OFF 상태에서는 스크롤/크기 변경에 따른 캔버스 그리기를 쉬고,
  ON으로 돌아오면 변경된 위치·크기를 반영합니다.
- 실시간 미리보기 버퍼를 미리 준비하고, 펜 이동 때마다 수행하던
  페이지 요소 탐색 및 스타일 조회를 제거했습니다.
- 펜을 놓을 때 완성된 선을 캔버스에 반영한 뒤 미리보기를 지웁니다.
  전체 기록 재생 대신 새 선을 추가해 선 사이의 대기 시간을 줄입니다.
- 전체 그림 기록 저장은 입력 이벤트에서 분리하여 200ms 뒤 유휴 시간에 처리합니다.
  그리는 동안은 저장을 미루며, 페이지를 떠나거나 숨겨질 때 남은 저장을 처리합니다.
- 펜을 누른 즉시 접점을 표시하고, 포인터 캡처로 드래그 중 입력을 이어 받습니다.
- 휠/트랙패드는 화면 아래의 실제 스크롤 창으로 전달합니다.
  내부 스크롤, 가로 스크롤, 도구 모음 및 텍스트 입력을 지원합니다.

권한
추가 권한은 요청하지 않습니다. 기존 manifest 권한을 유지했습니다.

검증 범위
Chromium 브라우저에서 ChatGPT 형태의 내부 스크롤 화면과 긴 일반 문서를
재현하여 원본과 수정본을 비교했습니다. 실제 ChatGPT 로그인 대화에서의
속도를 측정한 결과는 아닙니다. 자세한 수치는 함께 있는 검증 메모를 참고하세요.
