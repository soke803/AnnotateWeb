Annotate Web Chrome v1.2.0 - 빠른 켜기/끄기 + Option+물결표

- Chrome 툴바 아이콘 클릭: 주석 켜기/끄기
- Option(⌥)+` / ~ 키: 동일한 켜기/끄기 (일반 웹페이지에서만)
- 이전 방문 후 주석 기능을 사용했던 사이트는 다음 페이지 로드 후 화면이 안정되면 보이지 않게 엔진을 미리 준비합니다.
- 일반적인 켜기/끄기는 도구 모음을 삭제하지 않고 잠시 숨겼다가 복원하므로 재로딩이 없습니다.
- 선 보정, 화살표 커서, 기존 주석 저장 기능을 유지합니다.

주의 사항
- 단축키를 웹페이지에서 감지하기 위해 사이트 액세스 권한이 필요합니다.
- 키보드 배열/운영체제 단축키가 가로채는 경우 Option+`가 인식되지 않을 수 있습니다.
- 처음 사용한 사이트의 첫 실행은 엔진 초기화 시간이 필요합니다. 이후 같은 사이트를 새로 열 때는 미리 준비합니다.
- Chrome 설정/웹스토어/내장 PDF 뷰어 등에서는 사용이 제한됩니다.
- 기존 버전은 비활성화하고, 새로 설치한 뒤 해당 웹페이지를 새로고침하세요.
- 웹페이지의 저장된 주석은 사이트 데이터를 지우지 않는 한 유지됩니다.
