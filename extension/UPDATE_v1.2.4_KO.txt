Annotate Web v1.2.4 — ON/OFF 복구

설치: chrome://extensions에서 기존 버전을 끄고 이 폴더를 로드하거나,
기존 폴더에 덮어쓴 뒤 확장을 새로고침합니다.
업데이트 후 ChatGPT를 포함한 열려 있던 탭도 새로고침해주세요.
manifest.json이 바로 보이는 폴더를 선택해야 합니다.

켜기/끄기: 확장 아이콘, Alt/Option + `
끄기: 도구 모음 OFF 버튼 또는 Esc

수정 사항
- 도구 모음/오버레이가 없어져도 OFF가 재초기화 후 ON으로 바뀌지 않도록 수정.
- 설치 전에 열려 있던 탭에도 제어 스크립트를 복구.
- 메시지 응답 유실 시 같은 클릭이 두 번 토글되지 않도록 요청 식별.
- API 무응답에 제한 시간을 두어 다음 클릭의 영구 대기 방지.
- 초기화 실패 시 전역 이벤트를 정리해 페이지 클릭/스크롤 복구.
- 백그라운드 연결 오류가 있어도 이미 준비된 도구의 OFF/Esc 동작.
- 시작 시 외부 사이트 호출 및 사전 로딩 경쟁 제거.
- 오류 배지 !의 툴팁에서 원인 확인 가능.

화면 주변 최대 128px 캔버스 제한 등 이전 성능 개선을 유지합니다.
추가 권한은 없습니다.

테스트는 Chromium 페이지와 Chrome API를 대체한 백그라운드 VM으로 수행했습니다.
검증 환경의 관리 정책 때문에 실제 MV3 설치 및 Mac의 Status code: 10
오류를 직접 재현하지는 못했습니다. 해당 오류의 해결을 보증하지 않습니다.
