Annotate Web Chrome v1.2.2 - 전환 지연 개선

1) Option + ` (~ 키): 이미 로드된 페이지에서는 백그라운드 호출 없이 즉시 전환합니다.
2) Chrome 툴바 버튼: 거주형 스크립트로 직접 메시지 보내기 (빠른 경로).
3) 다시 켤 때 기존 Canvas를 재사용하고 필요할 때만 이전 기록을 다시 그립니다.
4) CSS/JS 초기 주입은 첫 클릭 시 여전히 필요할 수 있으며 단축키도 Chrome 내부 페이지에서는 실행할 수 없습니다.

설치: chrome://extensions → 개발자 모드 → 압축해제된 확장 프로그램 로드
기존 버전을 비활성화하고, 열려 있는 웹페이지를 새로고침하세요.
단축키는 Option + 키보드 맨 왼쪽 ` (~) 물리 키입니다.
