Annotate Web - Chrome Fast Toggle v1.2.1

변경 내용:
- Chrome Permissions Policy: unload is not allowed in this document 오류 제거
- draw.js 의 unload 이벤트 등록과 관련된 불필요한 해제 코드를 제거
- 기존 활성화/비활성화 처리, ⌥+` 단축키, 펜 보정, 화살표 커서 유지

설치:
1. 기존 버전의 확장 프로그램을 비활성화하거나 기존 설치 폴더를 이 버전으로 교체합니다.
2. chrome://extensions 에서 압축해제된 확장 프로그램을 로드하거나 새로고침합니다.
3. 사용 중인 웹페이지를 새로고침합니다.

주의: Chrome의 오류 페이지에 이미 기록된 오래된 오류는 수동으로 지우거나 새로고침해야 사라집니다.
이 수정은 위 unload 오류를 해결하는 것이며, 전체 기능의 실제 Chrome 동작이 자동 검증된 것은 아닙니다.
