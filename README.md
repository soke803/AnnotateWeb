# AnnotateWeb v1.2.4

긴 페이지의 주석 그리기 성능과 ON/OFF 상태 복구를 개선한 로컬 Chrome 확장 프로그램입니다. 사용자가 제공한 AnnotateWeb v1.2.2를 기반으로 합니다.

## 다운로드 및 설치

**[최신 수정 ZIP 다운로드](https://github.com/soke803/AnnotateWeb/releases/download/v1.2.4/AnnotateWeb_v1.2.4.zip)**

[저장소의 ZIP 파일](downloads/AnnotateWeb_v1.2.4.zip)에서도 Download raw file(↓)을 눌러 받을 수 있습니다.

1. ZIP을 압축 해제하고, 압축을 푼 폴더를 계속 보관할 위치에 둡니다.
2. Chrome의 `chrome://extensions`에서 개발자 모드를 켭니다.
3. 기존 1.2.2/1.2.3 확장 프로그램은 끕니다. 새로 설치한다면 **압축해제된 확장 프로그램을 로드합니다**에서 `manifest.json`이 바로 보이는 폴더를 선택합니다.
4. 기존 확장 폴더에 덮어쓰는 방식이라면 해당 확장의 새로고침 버튼을 누릅니다.
5. **이미 열려 있던 ChatGPT 탭도 반드시 새로고침합니다.** 이전 실행 코드와 새 코드가 함께 남지 않게 하는 업데이트 절차입니다.
6. 확장 아이콘 또는 **Alt/Option + `**로 켜고 끕니다. **Esc 또는 도구 모음의 OFF 버튼**으로도 끌 수 있습니다.

소스 전체를 Download ZIP으로 받은 경우에는 `extension` 폴더를 로드하면 됩니다.

## v1.2.4에서 고친 문제

- **켜진 뒤 OFF 실패:** 도구 모음/오버레이가 사라져도 OFF는 화면과 입력 차단부터 해제합니다. OFF 요청을 재초기화 후 ON으로 바꾸지 않습니다.
- **설치 이전에 열려 있던 탭:** 확장 아이콘을 누르면 누락된 토글 제어 스크립트를 설치하여 ON만 반복되는 경우를 복구합니다.
- **응답 유실/대기:** 요청 ID로 같은 클릭의 중복 토글을 방지하고, API 응답에 제한 시간을 두어 다음 클릭이 영구 대기하지 않게 했습니다.
- **초기화 중 실패:** 등록한 전역 이벤트를 추적해 정리하고, 페이지 클릭과 스크롤을 복구합니다. 저장소 접근 제한도 처리합니다.
- **백그라운드 연결 오류:** 이미 준비된 엔진에서는 OFF 버튼과 Esc가 백그라운드 메시지 없이 동작합니다.
- **시작 경로 단순화:** 시작 시 외부 사이트를 여는 동작과 기존 사전 로딩 경쟁을 제거했습니다. 그리기 엔진은 명시적인 ON 요청으로 로드합니다.
- **오류 진단:** 빨간 `!` 배지에 마우스를 올리면 실패 원인을 툴팁에서 볼 수 있습니다. 이후 클릭은 다시 시도할 수 있습니다.

v1.2.3의 화면 주변 최대 128px 캔버스 제한, 전체 페이지 스타일 재계산 제거, 펜 이동 중 요소 탐색 제거, 지연 저장은 유지했습니다. 새 권한은 추가하지 않았습니다.

## 검증 범위

`tests/toggle-recovery.cjs`는 실제 Chromium 페이지에 콘텐츠 스크립트를 실행하고 백그라운드 스크립트를 VM에서 실행하며, Chrome API 연결 부분을 대체합니다. 도구 모음/오버레이 삭제, 초기화 예외, 응답 유실·무응답, 워커 재시작, 단축키 및 OFF 복구를 검증합니다. 결과는 `TEST_RESULTS.json`에 있습니다.

일반 긴 문서, ChatGPT 형태의 내부 스크롤, 큰 sticky 요소에서 선 그리기, 실행 취소/다시 실행, 저장 복원, 한글 텍스트 입력 및 휠 동작도 검증했습니다.

**검증 환경의 관리 정책이 임의 확장 설치를 금지하여 실제 MV3 설치 및 사용자 Mac의 `Service worker registration failed. Status code: 10` 발생 환경을 직접 재현하지는 못했습니다.** 해당 코드만으로 Mac에서의 원인은 확정되지 않았으며, 이번 버전이 모든 환경의 워커 등록 오류를 해결한다고 보증하지 않습니다. Chromium 콘텐츠/컨트롤러 복구 테스트 결과와 실제 확장 설치 검증을 구분합니다.

## 복구 테스트 실행

Node.js와 Chromium이 설치된 환경에서:

```sh
npm install
npm test
```

기본 Chromium 경로는 `/usr/bin/chromium`입니다. macOS Chrome으로 실행하려면:

```sh
CHROMIUM_PATH='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' npm test
```

원본에 포함된 자산 및 과거 문서는 보존했습니다. 새 라이선스는 부여하지 않습니다.
